# Troubleshooting - DW-450 Dishwasher Error Codes

The Halden Aria DW-450 shows an error code on the control panel when it detects a problem. Find your code below and follow the steps. If the code returns after you follow the steps, file a warranty claim.

## How to reset the dishwasher

Press and hold **Start** for 3 seconds to cancel the cycle. If the code stays on, turn off the circuit breaker for 1 minute, then turn it back on.

## Water and drain codes

### E1: Water not filling

The dishwasher did not fill within 10 minutes.

1. Make sure the hot water shutoff valve under the sink is fully open.
2. Check that the inlet line is not kinked behind the dishwasher.
3. Check the water pressure. It must be at least 20 psi.
4. Reset the dishwasher and start a new cycle.

### E2: Drain problem

Water did not drain within 5 minutes.

1. Remove the bottom rack and clean the filter. Twist the cylindrical filter counterclockwise, lift it out, and rinse it under running water.
2. Check that the drain hose is not kinked.
3. If the dishwasher was just installed and connected to a garbage disposer, make sure the disposer knockout plug was removed.
4. Run the garbage disposer to clear it, then reset the dishwasher.

### E4: Leak detected

Water was found in the base pan, and the dishwasher has stopped the cycle and turned on the drain pump.

1. Turn off the dishwasher and the water supply.
2. Check for oversudsing. Using regular dish soap instead of dishwasher detergent causes excess suds that can trigger E4.
3. Tilt the dishwasher slightly forward to drain the base pan, or wait 24 hours for it to dry.
4. If E4 returns, do not use the dishwasher. Contact Halden support.

## Heating and sensor codes

### E3: Heating problem

The water did not reach the required temperature. Check that the water supply is set to 120 F. Run the kitchen faucet until the water is hot before starting the dishwasher. If E3 continues, the heating element may need replacement, which is covered by the warranty.

### E6: Temperature sensor fault

The temperature sensor sent an invalid reading. Reset the dishwasher. If E6 appears again, contact Halden support. This part is not user replaceable.

## Door codes

### d0: Door not latched

The door is not fully closed. Check that no dishes or utensils are blocking the door and press it firmly until it clicks.

## Status codes that are not errors

- **Ld:** The dishwasher is running a delayed start.
- **CL:** Child lock is on. Press and hold **Heated Dry** and **Delay** together for 3 seconds to turn it off.
